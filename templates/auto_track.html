📱 手机端如何实现“全自动记账”？

只需在 Android 手机上配合常见的自动化工具，每次扣款通知弹出，手机就会自动发给上面这个接口，你甚至不需要手动打开任何网页！

方案 A：MacroDroid（推荐：免开 App，后台静默记账并直接弹出手机原生通知）
  1. 在手机上打开 MacroDroid。
  2. 新建宏，触发器 (Trigger) 选择：通知 (Notification) → 已收到通知 → 勾选 Touch 'n Go eWallet、MAE 等银行/钱包。
  3. 动作 1 (Action) 选择：网页请求 (HTTP Request)：
    • 请求方式：POST
    • URL：填入上方复制的 ⭐ 一体化免 Header 接收地址（URL 已包含 Key，无需额外加 Header）
    • 请求头 (Headers)：若用了上方一体化地址，此处留空即可；若用标准地址可填 X-API-KEY: {{ api_key }}
    • 请求体格式：application/json
    • 内容填入：{"text": "[notification_text]"}
    • 响应存储：在下方勾选「保存响应结果」，将响应存储到字符串局部变量（如命名为 response）。
  4. 动作 2 (后台原生通知) 选择：通知 (Notification) → 显示通知 (Display Notification)：
    • 通知标题：{lv=response[notification_title]}（或填 自动记账成功 💸）
    • 通知内容：{lv=response[notification_body]}
  5. 点击保存启用！每次付款收到银行通知，MacroDroid 就会在后台自动完成记账，并直接在手机通知栏弹出记账结果通知，无需打开任何网页或 App，零打扰又即时！
⚠️ 调试重点提示：
  • 不要只测触发器：在 MacroDroid 触发器里点「测试匹配」只会验证正则规则，不会向服务器发送任何网络请求！
  • 如何真正测试发送：点击动作列表里的「网页请求」右侧三个点 → 【测试动作】，或点击宏右上角三个点 → 【测试宏】。
  • 查看排错原因：如果没收到记账，进入 MacroDroid 首页左上角抽屉菜单 → 【系统日志 (System Log)】，里面会明确显示 HTTP 状态码或具体失败报错（如超时、网络断开等）。
方案 B：Tasker 或 SmsForwarder（短信转发器）

如果你的银行发的是 SMS 短信通知，可以使用开源免费的 SmsForwarder，添加发送通道为 Webhook，把左侧 URL 填入，并在 Headers 请求头中添加 X-API-KEY: {{ api_key }} 即可。

💡 部署在 Render 上的优势：
当你把代码推送到 Render 后，把左侧地址中的域名换成你的 Render 公网二级域名，无论手机在户外用 5G 还是在家里，24 小时随刷随记！
